# Vish · Laminários

Visualizadores web de lâminas de histologia e patologia, publicados com GitHub Pages.

- **Laminário de Mama** (`mama/`): mama normal, lesões benignas, carcinomas in situ e invasivos, IHQ (RE, Ki-67, HER2, E-caderina) e FISH HER2/CEP17.
- **Laminário Bucal** (`bucal/`): histologia e patologia bucal para a odontologia.

Cada laminário é uma página HTML única. O visualizador usa [OpenSeadragon](https://openseadragon.github.io/) (carregado do cdnjs) e as lâminas desta versão são geradas por computador no próprio navegador, só para demonstração.

## Como publicar

Settings → Pages → *Build and deployment*: **Deploy from a branch**, branch `main`, pasta `/ (root)`.

## Observações

- Fora do Claude, as anotações ficam salvas apenas no navegador de quem as fez (localStorage).
- Os textos seguem a OMS (5ª ed.) e as diretrizes ASCO/CAP e devem ser revisados pela docente responsável.
